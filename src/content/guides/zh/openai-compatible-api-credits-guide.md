ChatGPT Plus 和 API 额度不是同一种东西。Plus 面向 ChatGPT 应用体验，API 额度面向客户端和开发工具调用模型。

## 使用这些工具时更应该看 API 额度

- Cursor
- Cline
- Claude Code
- ChatBox
- Cherry Studio
- NextChat
- 支持 OpenAI 兼容 API 的自定义工具

## 配置通常需要三个字段

- API Key：在控制台创建。
- Base URL：服务提供的 OpenAI 兼容接口地址。
- Model name：从控制台复制可用模型名。

## 不要混淆

- ChatGPT Plus 不等于 API 额度。
- API 额度不会给 ChatGPT Plus 续费。
- 不同模型和线路的可用性、扣费倍率可能不同。
