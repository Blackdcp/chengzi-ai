## 深度技术与架构解析 (Deep Tech Dive)

### 1. 测试时算力扩展定律（Test-Time Compute Scaling Law）

测试时算力扩展的核心在于模型并不是在单次自回归中匆忙输出结果，而是在隐藏的思维空间中构建一棵**蒙特卡洛树状验证分支**：

```
                    [输入 Prompt]
                          |
              +-----------+-----------+
              | (初始假设 A)          | (初始假设 B)
              v                       v
      [前向推导步骤 1]         [前向推导步骤 1]
              |                       |
              v                       x (逻辑矛盾，快速剪枝)
      [前向推导步骤 2]
              |
              v (状态自检通过)
      [最终结构化输出]
```

- **反思性自我修正（Self-Correction）**：当模型在思维链中推导出一个中间变量与题目已知前提产生冲突时，它能立即启动回溯（Backtracking）机制，否定初始假设并尝试新路径。
- **分步验证器（Step-wise Verifier）**：模型在训练阶段接受了数亿个细粒度推导步骤的强化学习（RL）打分，使其具备了极强的数学和代码语法纠错直觉。

### 2. reasoning_effort 参数调优矩阵

在调用 o3-mini 时，开发者必须针对业务场景精确设置思维强度参数：

```json
{
  "model": "o3-mini",
  "reasoning_effort": "high",
  "messages": [
    {
      "role": "user",
      "content": "请证明任意有限单群要么是循环群，要么是交错群，要么是李型单群，并给出素数阶特例分析。"
    }
  ]
}
```

- **Low（低强度）**：思维链长度约 500-1500 tokens。适合日常单函数编写、单元测试用例扩充、JSON Schema 校验。
- **Medium（中强度）**：思维链长度约 2000-5000 tokens。适合排查多线程死锁、重构复杂类结构、SQL 执行计划深度优化。
- **High（高强度）**：思维链长度可达 10000+ tokens。适合算法竞赛压轴题、形式化软件证明、复杂加密算法审计。
